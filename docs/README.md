## 🛠️ 구현할 기능 목록
### 1. 게임 시작 문구 출력 ☑️
### 2. 컴퓨터 난수 생성 로직 구현 ☑️
> 생성 조건
1. 1부터 9까지
2. 서로 다른 수로 이루어진
3. 3자리의 수
### 3. 사용자 입력 ☑️
1. 입력 메시지 출력
2. 입력의 유효성 확인 → 3자리의 서로 다른 숫자인지
   - 유효하지 않다면 `IllegalArgumentException`를 발생시킨 후 프로그램 종료
### 4. 2(컴퓨터 수)와 3(사용자가 입력한 수)의 결과 비교 ☑️
#### 1. 일치할 때
1. 게임 종료 문구 출력 ✔️
2. 게임 재시작 여부 묻기 ✔️
      - 사용자의 입력 처리
        - 1 → 게임 재시작 (2번 과정부터 반복)
        - 2 → 게임 종료
        - 기타 (유효하지 않은 값) → `IllegalArgumentException`를 발생시킨 후 프로그램 종료
#### 2. 일치하지 않을 때
1. 결과(힌트) 출력 ✔️
      1. 같은 수가 같은 자리에 있으면 → 스트라이크
      2. 같은 수가 다른 자리에 있으면 → 볼
      3. 같은 수가 전혀 없으면 → 낫싱
2. 3번 과정부터 반복 ✔️
